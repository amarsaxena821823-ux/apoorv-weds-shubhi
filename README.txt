PUBLISH ON VERCEL
1. Create/sign in to GitHub and create a new repository named apoorv-weds-shubhi.
2. Upload index.html and README.txt (and aaj-sajeya.mp3 only if you have permission to use it).
3. Sign in to Vercel with GitHub.
4. Choose Add New -> Project, import the repository, and deploy.
5. Vercel will provide a free *.vercel.app URL. You can set the project name to apoorv-weds-shubhi if available.

This is a static site; no build command or framework is required.
Check the date/time and venue details before sharing publicly.
